# L1017n — متجر رقمي جديد

واجهة عربية RTL بتصميم جديد كلياً، مستقلة عن مستودعات المتجر القديم والبوت.

## التشغيل
افتح `index.html` محلياً أو انشر المستودع على Netlify كـ static site.

## المزايا الموجودة في الواجهة
- واجهة رئيسية ومتجر وبطاقات منتجات تجريبية.
- صفحة محفظة مع اختيار ليبيانا أو المدار الجديد.
- حساب كود تحويل ليبيانا وفق الصيغة المتفق عليها: `*122*0925620538*{المبلغ × 1000}#`.
- رقم تحويل المدار الجديد: `218910005566`.
- نموذج طلب شحن وحالة انتظار ومراجعة محلية على نفس الجهاز.

## مهم قبل الاستخدام الحقيقي
هذه نسخة واجهة أولية؛ طلبات الشحن محفوظة محلياً في المتصفح فقط ولا تصل إلى الإدارة، وتغيير الحالة/اعتماد الرصيد ليس متاحاً بعد. **لا تستخدمها لاستقبال أموال حقيقية حتى ربطها بقاعدة بيانات مستقلة وسياسات وصول آمنة ولوحة إدارة**. لا تستخدم قاعدة المتجر القديم إذا كان الهدف فصل البيانات.
